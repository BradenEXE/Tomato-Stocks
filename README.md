## What is Tomato-Stocks?

Tomato-Stocks is a game developed by me and my friend where you grow tomatoes to escape from a life of poverty and homelessness.
You start with a single dollar... Will you come out rich or stay poor? 
Download Tomato-Stocks today and find out!


## Installation and Issues 

### Installation

To install tomato stocks you need to...
1. Go to Releases and find the latest version
2. Download the .ZIP file (it will be called Tomato-Stocks-v#.#.#)
3. Unpack the .ZIP file and run the .exe file


### Issues

Because the Tomato-Stocks exe is not signed it is not recognized by Windows, there-for Windows will say it protected your PC. 

Please Note: **THIS SOFTWARE IS NOT A VIRUS AND HAS NO INTENTION TO HARM YOUR DEVICE**

To fix this issue go to...
```More Info > Run anyway```
